# 토코 — Claude Code 안에 사는 쉼표 같은 펫

토코는 Claude Code 터미널의 프롬프트 바로 위에 사는 픽셀 동반자입니다. Claude가 일하는 동안 띠 위에서 숨 쉬고 걸어 다니다가, 작업이 끊긴 틈에 다가와 잠깐 쉬자고 하거나 하던 일을 한 줄로 짚어 줍니다.

토코의 목적은 하나입니다. **AI와 일하며 쌓인 인지 부하를 덜어 주고, 숨을 돌린 뒤 가벼운 마음으로 일에 돌아가게 하는 것**입니다. 그래서 토코는 이렇게 동작합니다.

- 말은 틈에서만 겁니다. 턴이 끝난 직후나 타이핑을 멈춘 뒤에만 말을 걸고, Claude가 일하는 동안에는 입력을 빼앗지 않는 조용한 연출만 합니다.
- 보상은 토큰을 많이 쓴 것보다 쉬는 습관에 줍니다. 토큰 수입은 로그 곡선이라 많이 쓸수록 덜 늘고 하루 상한이 있습니다. 휴식을 받아들인 보상은 상한 밖이고 더 큽니다.
- 잃는 장치가 없습니다. 며칠 안 와도 펫과 코인은 그대로입니다.
- 명령 한 번으로 조용히 할 수 있습니다. 거절이 두 번 이어진 권유는 스스로 빈도를 절반으로 줄입니다.

하지 않는 것도 정해 두었습니다. 토코는 Claude의 작업 내용을 바꾸지 않고 관찰만 합니다. 생산성이 몇 퍼센트 오른다고 약속하지도 않습니다.

## 설치

Claude Code 터미널 세션의 프롬프트에서 입력합니다.

```text
/plugin install toko --marketplace teamdable/toko-plaza
```

마켓플레이스를 추가할지 물으면 `y`를 누르고, 범위를 고릅니다. 셸에서는 이렇게 설치합니다.

```bash
claude plugin install toko --marketplace teamdable/toko-plaza
```

데스크톱 앱에서는 프롬프트 옆의 + → Plugins → Add marketplace에 `teamdable/toko-plaza`를 넣고 Add plugin을 누릅니다. 데스크톱과 VS Code 화면에서는 픽셀 그림 대신 한 줄 글로 보입니다.

## 전체 구조

토코는 Claude Code의 모드(훅 모듈로 화면 · 명령 · 도구를 넓히는 플러그인) 하나입니다. 다른 사람의 펫과 만나는 광장은 선택 기능이고, 광장 서버를 따로 띄웠을 때만 켜집니다.

```text
사용자 ──프롬프트·단축키──▶ Claude Code ──턴·도구 결과·사용량──▶ 토코 모드
                                ▲                                 │
                                └──── 셀 그림 · 말풍선 · 명령 결과 ◀┘
토코 모드 ──펫 대사·의도 결정──▶ 작은 모델(Haiku, 사용자 세션의 자격 증명)
토코 모드 ◀──SSE로 친구·손짓── 광장 서버
토코 모드 ──상태가 바뀔 때 보고──▶ 광장 서버 ──짧은 인사말──▶ LLM 게이트웨이(선택)
```

| 구성 | 역할 |
|---|---|
| 지각기 | Claude Code가 알린 일(턴 시작·끝, 테스트 실패·통과, 커밋 · 푸시, 권한 대기)을 펫이 알아듣는 사건으로 바꿉니다. 커밋 · 푸시는 Claude Code가 따로 알려 주지 않아도 실행한 명령에 `git commit` · `git push`가 있으면 셉니다(`--dry-run`은 세지 않습니다) |
| 시뮬레이션 코어 | 욕구(기운·재미·배고픔·교감)와 기분을 시간에 따라 바꾸고, 지금 할 수 있는 행동 후보에 점수를 매깁니다 |
| 참견 게이트 | 지금이 틈인지 판단하고, 시간당 말풍선 4번 같은 빈도 상한과 방해 금지 시간을 지킵니다 |
| 성격 층 | 작은 모델로 펫의 영혼(이름·성격·말버릇)을 짓고 틈마다 무엇을 할지 고릅니다. 작은 모델은 하루 30번까지 부르고, `/toko ai 60`처럼 10~200 사이로 바꿀 수 있습니다. 틈마다 할 일 고르기 · 복귀 브리핑 · 회고 · 새 기능 소개 · 뿅망치 전광판 유형 고르기처럼 토코가 스스로 부르는 일은 한도보다 5번 적은 데서 멈추고, 남은 5번은 사람이 직접 부른 일(`/toko today` 정리 · `/toko sessions <이름>` 요약 · 뿅망치 이유 판정과 교정 문장 · `/toko event update`)이 씁니다. 실패하거나 한도를 다 쓰면 규칙과 준비된 대사로 대신합니다 |
| 경제 | 턴 수입과 휴식 보상을 코인으로 바꾸고 상점 지출을 처리합니다 |
| 렌더링 엔진 | 반블록(▀ ▄)과 트루컬러로 장면을 그리고, 화면 전체를 다시 그리지 않고 바뀐 셀만 바꿔 넣습니다 |
| 광장 | 접속한 사람들의 펫이 서로 손을 흔들고, 하트와 간식을 나누고, 다 같이 기지개를 켭니다. Claude를 오래 기다리는 동안에는 똑같이 기다리는 친구의 펫이 놀러 오고, 오늘 Clawd가 맞은 이유는 뿅망치 전광판에 모입니다. 광장 주소를 브라우저로 열면 모인 펫들이 보입니다 |
| 옆 세션 소식 | 같은 컴퓨터의 다른 세션이 답을 마치거나 권한 확인을 기다리면, 지금 보고 있는 세션의 펫이 그 세션의 탭 제목(/rename 이름, 없으면 AI가 지은 제목)을 색으로 짚어 말풍선으로 알려 주고, "요약 보기 · 다음 일 보내기 · 괜찮아" 대답을 붙입니다. 요약 보기는 그 세션이 한 일을 대화창에 띄우고, 다음 일 보내기는 입력창에 `/toko send <그 세션> `을 채워 둡니다. 다른 권유가 떠 있으면 말풍선만 띄우고, 이 알림은 시간당 말풍선 횟수에 세지 않습니다. 알림을 놓쳐 허락 대기가 10분, 끝남이 30분 넘게 그대로면 "「배포」 12분째 확인을 기다려" · "「리뷰」 끝난 지 31분 됐어. 안 봐도 돼?"처럼 한 번 더 짚고 같은 대답을 붙입니다. 어느 탭에서든 대답했거나 한 번 짚은 세션은 상태가 바뀌기 전까지 다시 묻지 않고, 집중 타이머 · 방해 금지 시간 · `/toko peers off`일 때는 짚지 않습니다. `/toko sessions` 로 옆 세션 목록과 요약을 보고(세션이 둘 이상이면 허락을 가장 오래 기다린 세션, 없으면 가장 오래전에 끝난 세션을 맨 위 "먼저 볼 것"으로 짚습니다. 번호는 시작한 순서 그대로입니다), `/toko send 배포 로그 봐 줘`처럼 탭 이름 일부(대소문자 무시)나 목록 번호로 고른 세션에 할 일을 보냅니다. 이름이 여러 세션에 맞으면 보내지 않고 후보를 보여 줍니다. `send` 대신 `보내`를 써도 되고, `토코야 배포한테 로그 봐 줘라고 보내줘`처럼 세션 이름부터 말해도 보냅니다. 그 밖의 말로 부탁하면 Claude가 `/toko send …` 명령을 입력창에 채워 두고, 엔터를 눌러야 보내집니다(Claude가 다른 세션에 직접 넣지는 못합니다). 보낸 질문은 그 세션이 답을 마치면 답이 보낸 세션 대화창에 뜹니다(짧으면 그대로, 길면 앞 여섯 줄) |
| 기록 | 휴식 · 테스트 · 커밋 · 편집 줄 수 · 비용 · 뿅망치 · 옆 세션 보기와 보내기 · 오늘 정리 횟수를 터미널마다 따로 세고 합쳐서(날짜별로 최근 30일), 업적 · 퀘스트 · 오늘 요약에 씁니다. `/toko today` 는 세션마다 턴 끝에 남긴 질문·답 앞부분으로 오늘 한 일과 진행 중인 일을 일 단위로 정리합니다(닫힌 세션 포함) |
| 터미널 사이 동기화 | 펫 · 보관함 · 설정 · 지갑 같은 공용 상태를 4초마다 저장소와 맞춥니다. 다른 터미널이 바꾼 값은 받아오고 이 터미널이 바꾼 값만 써서, 이름이나 숨김 설정이 다른 터미널의 옛 값에 덮이지 않습니다. 코인은 양쪽에서 늘고 준 만큼을 모두 더합니다 |

레포는 마켓플레이스 하나에 두 폴더로 나뉩니다.

| 경로 | 내용 |
|---|---|
| `.claude-plugin/marketplace.json` | 이 레포를 마켓플레이스로 만드는 파일 |
| `plugin/` | 토코 모드. 설치하면 이 폴더만 쓰입니다 |
| `server/` | 광장 서버. 의존성 없는 Bun 프로그램 하나(`plaza.ts`)와 현황 페이지(`page.html`)입니다 |

## 쓰는 법

### 띠와 말로 하기

프롬프트 위 띠에 펫이 삽니다. 띠에는 단추를 두지 않고, 먹이 · 놀기 · 방 열기 · 권유에 답하기는 모두 말로 합니다. `/toko 먹이 줘`, `/toko 방 보여 줘`처럼 말을 걸면 Claude가 토코가 되어 맞는 명령을 실행합니다.

슬래시 없이 `토코야 오늘 퀘스트 뭐야?`처럼 불러도 `/toko`와 같습니다. 펫 이름을 지었으면 `말랑아 …`처럼 그 이름에 아/야를 붙여 불러도 됩니다. 입력창에 직접 친 글만 알아듣고, 옆 세션에서 넘어온 글은 그대로 둡니다.

토코가 무언가를 권하면 띠 아래 줄에 "대답: 좋아 · 나중에 · 오늘은 그만 — /toko 로 말해 줘"처럼 고를 수 있는 대답이 뜹니다. `/toko 좋아, 물 마실게`처럼 말로 답하거나 `/toko answer 좋아`(선택지 이름이나 accept 같은 키)로 바로 답합니다. 말을 거는 동안에는 권유가 사라지지 않습니다. `토코야 좋아`처럼 대답 이름만 말하면 Claude를 거치지 않고 토코가 바로 받습니다. `토코야 좋아, 물 마실게`처럼 말을 덧붙이면 Claude가 알아듣고 답합니다. "요약 보여줘" · "열어" · "지워줘"처럼 그 권유에만 쓰는 동작은 이름 없이 그 말만 쳐도 토코가 받습니다. "좋아" · "괜찮아" · "나중에"처럼 Claude에게도 하는 대답이나 "이 PR 요약해줘"처럼 다른 일을 시키는 말은 그대로 Claude에게 갑니다.

벌레 잡기 미니게임만은 실시간이라, 게임하는 30초 동안 띠에 ◀ · 잡기 · ▶ 단추가 뜹니다. 띠에 포커스를 주면 a · s · d로도 움직입니다.

### 이름 짓기

알이 깨지면 펫이 바로 이름을 지어 달라고 합니다. Claude가 일하는 중이면 말풍선 없이 띠에 "이름 짓기: 입력창에 이름만 써서 보내 줘"만 띄우고, 턴이 끝나면 한 번 말로 묻습니다. 이 물음이 떠 있는 동안 입력창에 이름만(예: `콩떡`) 써서 보내면 Claude에게 가지 않고 그대로 이름이 됩니다. 띄어쓰기가 있는 문장, "응" · "ㅇㅇ" · "계속" 같은 대답, "커밋해줘"처럼 부탁하는 말, `continue` 같은 명령어는 평소처럼 Claude에게 갑니다. "이름 지어 주기"라고 하면 입력란에 `/toko name `을 채워 주고, "네가 지어"라고 하면 작은 모델이 지어 둔 이름을 그대로 씁니다. 답하지 않아도 이 물음은 사라지지 않고, 이름이 정해질 때까지 띠에는 "이름 없음"으로 보이며 할로윈 같은 우연한 장면도 나오지 않습니다. 새 기능 소개와 팁도 이름을 지은 뒤에 꺼냅니다. 이름은 띄어쓰기 없는 한 낱말에 12자까지이고, `/toko name <새 이름>`으로 언제든 바꿀 수 있습니다.

### 쉬자는 권유

틈이 오면 토코가 지금 상황에 맞는 권유를 하나 고릅니다. 가만히 있는 쪽을 고르기도 합니다. 30초 동안 아무것도 누르지 않으면 조용히 물러나고, 거절로 세지 않습니다.

| 권유 | 조건 |
|---|---|
| 기지개 | 쉬지 않고 일한 시간이 휴식 간격(기본 50분)을 넘었습니다 |
| 먼 곳 보기 | 20분마다 20초 동안 화면 밖을 봅니다 |
| 물 한 모금 | 하루 3번 이내 |
| 일찍 쉬기 | 사용 한도가 80%를 넘었거나 밤이 늦었습니다 |
| 복귀 브리핑 | 10분 넘게 자리를 비웠다 돌아오면 하던 일을 한 줄로 짚어 줍니다 |
| 막힘 풀기 | 같은 테스트가 세 번 이어서 실패하면 2분만 일어났다 오자고 하고, 돌아오면 실패 요약을 보여 줍니다 |
| 마무리 정리 | 정한 퇴근 시각이 지나면 오늘 한 일을 정리해 기록에 남깁니다 |
| 다 같이 기지개 | 광장에 친구가 있으면 함께 기지개를 켭니다 |
| 선물 · 벌레 잡기 · 수다 | 하루 1~2번 깜짝 선물, 테스트를 통과시킨 직후 30초 놀이, 오래 말이 없을 때 한마디 |

Claude의 턴이 1분을 넘기면 말풍선 없이 20초짜리 먼 곳 보기 카운트다운만 띄웁니다.

광장에 들어가 있으면 턴이 30초를 넘길 때 지금 똑같이 Claude를 기다리는 친구 한 명의 펫이 띠에 놀러 옵니다. 스피너 줄에는 "콩떡(여우) (•ᴗ•)ﾉ Claude 기다리는 중이래. 같이 기다리자"가 뜨고, 턴이 끝나면 친구 펫은 돌아갑니다. 한 턴에 한 번, 10분에 한 번까지만 옵니다.

### 랜덤 인카운터

작업 중이거나 잠깐 손을 쉬는 동안, 6분에 한 번쯤 띠에 작은 장면이 지나갑니다. 말을 걸지 않고 눈을 쉬게 하는 장면들입니다.

| 장면 | 때 |
|---|---|
| 나비 따라가기 | 낮 |
| 떨어지는 잎 보며 앉아 있기 | 언제나 |
| 토큰 부스러기 냠 | 일하는 중에 자주 |
| 비눗방울 불기(숨을 들이쉬고 길게 내쉬기) | 걱정이 많은 날에 자주 |
| 별똥별 보기 | 저녁과 밤 |
| 비구름과 우산 | 언제나 |
| 새싹에 물 주기 | 쉬는 중에 자주 |
| 반딧불이 | 저녁과 밤 |

처음 본 장면은 인카운터 도감에 올라가고 5코인을 받습니다. 16번에 한 번꼴로 반짝이가 붙은 장면이 나오는데, 종류마다 처음 보면 15코인을 더 받고 도감에 ✦가 붙습니다. 나비는 낮에만, 별똥별과 반딧불이는 저녁과 밤에만 나오니 다 모으려면 여러 시간대에 써야 합니다. `/toko dex`나 방에서 도감을 봅니다.

### 분풀이

Claude가 엉뚱한 일을 했을 때 이유 한 줄과 함께 부탁합니다.

```text
/bonk 테스트 지우지 말랬잖아
```

토코가 Claude Code의 주황색 마스코트 Clawd를 꺼내 놓고 뿅망치를 들고 달려가 때리고, 맞은 Clawd는 납작해집니다. 턴이 도는 중이면 스피너도 "아야…"로 바뀝니다. 끝나면 토코가 Claude에게 짧은 메시지를 보내고, Claude는 "아야…"로 받아들인 뒤 바로잡고 사과 도구를 부릅니다. 마지막에는 숨 고르기(4초 들이쉬고 6초 내쉬기)나, 불만을 정중한 교정 문장으로 다듬어 다음 프롬프트에 넣기를 고릅니다. 화풀이로 끝내지 않고 진정이나 교정으로 끝내려는 장치입니다.

같은 잘못으로 또 때리면 토코가 Claude에게 그 내용을 auto memory에 피드백으로 남겨 달라고 덧붙입니다. 토코는 최근 뿅망치 이유 20개를 기억해 두고, 새 이유가 그중 하나와 같은 종류인지 작은 모델에게 물어봅니다(모델을 끄면 글자가 많이 겹치는지로 봅니다). 처음 맞은 이유는 바로잡고 사과받는 걸로 끝내고, 두 번째부터만 기억시킵니다. CLAUDE.md는 세션마다 통째로 읽혀서 쌓일수록 무거워지니, CLAUDE.md에는 쓰지 말고 비슷한 메모가 있으면 그걸 고치라고 함께 부탁합니다. 이럴 때는 마지막 말풍선이 "또 같은 일이라 기억해 두라고 했어"로 시작합니다. Claude Code의 `/memory`에서 Auto-memory가 켜져 있어야 남습니다. 뿅망치 횟수와 같은 잘못으로 또 맞은 횟수는 기록에 남아, `/toko <말>`로 토코와 이야기할 때 Claude에게 넘기는 오늘 기록에 "뿅망치 3번 · 같은 잘못 1번"처럼 들어갑니다.

광장에 들어가 있으면 토코는 뿅망치 이유를 정해진 유형 하나로 골라 광장의 뿅망치 전광판에 보냅니다. 유형은 안 돌려 보고 됐다고 함 · 시키지 않은 것까지 고침 · 같은 실수를 또 함 · 말한 걸 안 지킴 · 없는 걸 지어냄 · 테스트를 지우거나 건너뜀 · 엉뚱한 데를 고침 · 묻지 않고 위험한 걸 함 · 말이 너무 김 · 같은 데서 맴돎 · 그 밖의 실수 · 그냥 때림, 이렇게 12가지입니다. 유형은 작은 모델이 고르고, 모델을 끄거나 한도를 다 썼으면 이유에 든 낱말로 고릅니다. Claude가 한 일을 짚는 이유라면 "왜 영어로 말해"처럼 말투나 언어를 탓해도 잘못 유형 가운데서 고르고, 딱 맞는 게 없으면 그 밖의 실수로 칩니다. "돼지야"처럼 Claude가 한 일을 짚지 않는 장난이나 놀림만 그냥 때림으로 셉니다. 광장에는 이유 문장 없이 유형만 보냅니다. 전광판은 한국 시간 자정마다 0부터 다시 세고, `/toko plaza`를 치면 "뿅망치 전광판: 오늘 Clawd가 7번 맞았어요 · 1위 안 돌려 보고 됐다고 함(4번), 2위 테스트를 지우거나 건너뜀(3번)"처럼 3위까지 보여 줍니다. 광장 현황 페이지에도 같은 전광판이 뜹니다.

### 코인과 성장

`/toko coins`를 쓰면 지금 가진 코인과 아래 모으는 법을 터미널에서 바로 봅니다.

| 방법 | 코인 | 비고 |
|---|---|---|
| 턴 끝내기 | 출력 토큰만큼(아래 표) | 하루 500코인까지, 캐시를 절반 넘게 읽은 턴은 1.2배 |
| 휴식 받아들이기 | 기지개 15 · 마무리 정리 20 · 집중 끝까지 10 · 광장 같이 기지개 10 · 먼 곳 보기 5 · 숨 고르기 5 | 하루 상한 없음 |
| 오늘의 퀘스트 | 하나에 5, 셋 다 하면 10과 선물 상자 | `/toko quests` |
| 인카운터 처음 보기 | 5, 반짝이면 15 더 | `/toko dex` |
| Claude Code 기능 처음 쓰기 | 5 | `/toko features` |
| 업적 | 10~80 | `/toko badges` |
| 보스 쓰러뜨리기 | 20 | 같은 테스트가 3번 실패한 뒤 통과 |
| 벌레 잡기 | 한 마리에 2, 최대 20 | 테스트를 통과시킨 직후 30초 |

턴이 정상으로 끝나면 출력 토큰으로 코인을 법니다. 공식은 `round(9 × log2(1 + 출력 토큰 / 500))`이고, 캐시를 절반 넘게 읽은 턴은 1.2배입니다. 토큰 수입은 하루 500코인에서 멈춥니다. 펫이 스스로 부른 모델 사용량은 수입에 넣지 않습니다.

| 출력 토큰 | 코인 |
|---|---|
| 500 | 9 |
| 1,500 | 18 |
| 7,500 | 36 |
| 50,000 | 60 |

기지개를 받아들이면 15코인, 먼 곳 보기를 끝까지 하면 5코인, 마무리 정리는 20코인입니다. 휴식 보상은 하루 상한 밖입니다. 펫은 알 → 아기 → 어린이 → 어른으로 자라는데, 기준은 쓴 토큰이 아니라 함께한 날 수와 받아들인 휴식 수입니다. 자라도 모습은 아기 때 그대로입니다.

### 애완동물

상점의 애완동물 칸에서 작은 동물을 데려올 수 있습니다. 병아리는 60코인, 햄스터는 90코인, 아기 토끼는 100코인, 아기 고양이와 강아지는 120코인입니다. 데려온 동물은 띠에서 토코 뒤를 졸졸 따라다닙니다. 토코가 앉으면 같이 앉고, 잠들면 같이 눈을 감습니다. 방에서는 토코 옆에 앉아 있습니다. 한 번에 한 마리만 데리고 다니고, 바꾸는 법은 모자와 같습니다. 꾸미기에서 고르거나 `/toko wear <id>`를 쓰면 됩니다. 밥을 챙기지 않아도 굶거나 떠나지 않습니다.

### 방 꾸미기

방은 벽 2칸, 바닥 4칸, 가운데 러그 1칸으로 나뉩니다. 상점의 방 치장 칸에서 액자 · 창문 · 시계, 쿠션 · 어항 · 책장 · 캣타워, 줄무늬 · 꽃 · 구름 러그를 살 수 있고, 사면 맞는 빈자리에 바로 놓입니다. 빈자리가 없으면 창고에 들어갑니다. 방의 자리 단추를 누르면 그 자리에 맞는 장식이 차례로 바뀌고, 마지막에는 비워집니다. 명령으로는 `/toko place <id> [자리]`, `/toko store <id>`, `/toko layout`을 씁니다.

장식을 놓으면 반짝이가 터지고 토코가 달려가 살펴봅니다. 방에서 토코는 9초마다 놓인 장식 하나를 골라 그 옆에서 지냅니다. 쿠션에서 낮잠을 자고, 어항을 들여다보고, 러그에서 뒹굽니다. 밤 8시부터 아침 7시까지는 무드등이 켜지고 창밖이 밤하늘로 바뀌며, 무드등이 있으면 그 옆에서 잡니다.

상점 칸은 간식 · 캐릭터 치장(망치) · 애완동물 · 방 치장으로 나뉘고, 꾸미기도 캐릭터 꾸미기와 방 꾸미기로 나뉩니다. 벽지 6가지와 바닥재 4가지는 방 전체의 색을 바꿉니다. 창밖은 아침 · 낮 · 노을 · 밤으로 바뀝니다.

숲 · 카페 · 우주 · 바다 테마 세트는 가구 뽑기(`/toko gacha furniture`, 50코인)에서만 나오고, 한 세트 4점을 다 놓으면 방 위쪽에 덩굴 · 김 · 별 · 물방울이 생깁니다. `/toko furniture`나 방에서 가구 도감(세트별 모은 수, 다 모은 세트에 ✦)을 봅니다. 펫 뽑기에서 이미 가진 종족이 나오면 꽝 대신 별조각 1개를 받고, 별조각 5개로 뽑기에서 나오는 아이템 하나를 고릅니다(`/toko exchange <id>`).

장식이 많이 놓인 방일수록 토코의 교감 욕구가 천천히 줄어듭니다. 숫자로 보여 주지 않고 토코의 기분으로만 드러납니다. 먹이를 주거나 놀아 주면 방에서도 먹고 뛰는 모습이 나옵니다.

### 휴식 기념품

받아들인 휴식이 쌓이면 방에 기념품이 생깁니다. 물 한 모금 30번이면 물병, 기지개 50번이면 요가 매트, 먼 곳 보기 100번이면 망원경입니다. 인카운터를 처음 보면 인카운터 액자가, 업적을 처음 받으면 트로피 선반이 생기고, 선반에는 받은 업적만큼 트로피가 섭니다(세 개까지). 기념품은 코인으로 살 수 없고 쉬어야만 생깁니다. 시연할 때는 `/toko event souvenir`로 다음 기념품을 바로 받습니다.

### 친구 방에 놀러 가기

광장 친구 목록의 놀러 가기를 누르거나 `/toko visit <친구>`를 쓰면, 토코의 분신이 친구 방에 들어가 지냅니다. 데려오기(`/toko home`)를 하거나 친구가 배웅할 때까지 머물고, 어느 쪽이 Claude Code를 껐다 켜도 손님은 그대로 남습니다. 내 띠의 토코는 자리를 지키며 휴식 권유를 계속합니다. 한 방에 손님은 둘까지입니다.

방 주인과 손님은 안아 주기 · 간식 나눠 먹기 · 술래잡기 · 같이 낮잠으로 함께 놉니다. 방의 손님 단추나 `/toko guest <손님> hug|snack|play|nap|bye`로 하고, 하면 방에 하트 · 쿠키 · 음표 · Zzz가 뜨며 상대 쪽 토코도 말풍선으로 알려 줍니다. 손님이 없을 때도 토코는 가끔 손님 옆에 가서 손을 흔듭니다.

놀러 간 토코는 거기서 한 일을 기억했다가, 돌아오면 "콩떡네 방에서 같이 낮잠을 잤던 게 제일 재밌었어!"처럼 말합니다. 방 주인 토코는 다녀간 손님을 손님 앨범에 남기고, 또 온 손님은 먼저 반깁니다. 놀러 간 동안 친구 방 보기를 누르면 내 방 자리에 친구 방이 열립니다. 손님을 받고 싶지 않으면 `/toko room-open off`로 방 문을 닫습니다.

친구 방에는 방명록 스티커(하트 · 별 · 꽃)를 하루 세 장까지 붙일 수 있고(`/toko sticker <친구> <종류>`), 스티커는 방 벽 위쪽에 열두 장까지 남습니다. `/toko gift <친구> <id>`로 상점의 방 장식을 사서 친구에게 보내면, 친구가 광장에 다시 들어올 때 받아 방에 놓고 보낸 사람의 이름이 남습니다. 이미 가진 장식이면 별조각으로 바뀝니다.

`/toko doing auto`로 켜면 광장 친구 목록의 내 이름 옆에 지금 하는 일이 "코드 고치고 있는 중..." · "테스트 돌리고 있는 중..."처럼 뜹니다. 일하는지 쉬는지가 드러나 감시처럼 느껴질 수 있어서 기본으로 꺼져 있고, 현황 페이지에는 켜도 보이지 않습니다. 문구는 Claude가 쓴 도구 종류로 고르는 정해진 낱말이라 코드와 프롬프트는 나가지 않습니다. `/toko doing <문구>`로 20자까지 직접 정하거나 `/toko doing off`로 끕니다.

### 패션 · 애완동물 뽑기

모자(털모자 · 리본 · 작은 왕관 · 야구모자 · 베레모 · 꽃핀 · 고깔모자), 목에 거는 것(목도리 · 나비넥타이 · 반쪽 하트 목걸이), 안경(동그란 안경 · 선글라스 · 하트 안경), 등(천사 날개 · 작은 가방 · 망토), 손(풍선 · 꽃다발 · 머그컵)은 상점에서 팔지 않고 패션 뽑기로만 얻습니다. `/toko dye <id>`(10코인)로 모자 · 목 · 등 · 손 아이템을 기본 · 바다색 · 숲색으로 물들입니다. 반쪽 하트 목걸이를 한 두 펫이 한 방에 있으면 서로 붙어 앉아 하트를 띄웁니다. 이미 가진 것은 그대로 입을 수 있습니다. 안경은 종족마다 다른 눈 위치에 맞춰 씌웁니다. `/toko gacha fashion`과 `/toko gacha pet`은 각각 50코인이고, 아직 없는 것 중에서 하나가 무작위로 나와 바로 입거나 데려옵니다. 다 모았으면 코인을 받지 않습니다. 방의 뽑기 칸에도 같은 단추가 있습니다.

### 보스전

같은 테스트가 세 번 이어서 실패하면 띠 오른쪽에 왕관 쓴 보스가 나타나고, 상태줄에 "보스 버그 대왕 ■■■■■ 3/3"처럼 체력 바가 붙습니다. 체력은 테스트 출력에서 읽은 실패 개수입니다(jest · vitest · pytest · cargo · mocha · go test). 실패가 줄면 바가 줄고, 개수를 읽지 못하면 꽉 찬 채로 둡니다. 그 테스트가 통과하면 토코가 달려가 보스를 쓰러뜨리고 20코인을 받습니다. 이름은 테스트 명령마다 정해져서 같은 테스트는 늘 같은 보스가 나옵니다. 시연할 때는 `/toko event boss`를 세 번 쓰면 등장, 체력 감소, 격파 순서로 보여 줍니다. 시연으로 쓰러뜨리면 코인은 주지 않습니다.

### 할로윈 한정

10월 24일부터 11월 1일까지는 할로윈입니다. 이 기간에는 인카운터 대신 호박 등불 옆으로 박쥐가 날아가는 할로윈 장면이 가끔 나오고, 패션 뽑기를 하면 호박 모자가 가장 먼저 나옵니다. 기간이 지나면 호박 모자는 뽑기에서 빠지지만, 이미 받은 모자는 그대로 남아 계속 쓸 수 있습니다. 할로윈 장면은 인카운터 도감 8종에 세지 않아서 도감 완성 업적에는 영향이 없습니다. 시연할 때는 `/toko event halloween`으로 바로 띄웁니다.

### 펫 뽑기

코인 200개로 새 펫을 뽑습니다. 새 펫은 알로 나와 바로 깨어나고, 이름과 성격은 처음 알을 깰 때처럼 새로 짓습니다. 지금 데리고 다니던 펫은 보관함으로 가고, 보관함의 펫은 언제든 다시 데리고 다닐 수 있습니다. 성장 단계 · 이름 · 성격은 펫마다 따로 남습니다. 배고픔 같은 상태와 펫이 배운 내 습관은 모든 펫이 함께 씁니다.

| 등급 | 확률 | 종족 |
|---|---|---|
| 노말 | 90% | 고양이 · 곰 · 병아리 · 토끼 · 개구리 · 펭귄 · 여우 · 용 · 데불이 |
| 레어 | 10% | 유니콘 · 유령 · 불사조 · 로봇 · 우파루파 |

등급을 먼저 정하고, 그 등급 안에서는 종족마다 확률이 같습니다. 이미 가진 종족이 나오면 꽝이라 코인만 쓰고 끝납니다. 14종을 다 모으면 더는 뽑지 않고 코인도 빼지 않습니다. 종족이 생기기 전에 키우던 펫은 고양이로 이어집니다. 데불이는 데이블 캐릭터를 [캐릭터 가이드](https://dableglobal.notion.site/Dable-Character-Guide-5d1418b42a75435eabffd8b4b9b6edfb)의 색과 생김새(하늘색 몸 · 귀깃 · 남색 눈의 노란 초승달 · 흰 배)대로 16칸 픽셀로 옮긴 종족입니다.

### 업적과 오늘의 퀘스트

업적은 22개입니다. 휴식(첫 쉼표 · 쉼표 수집가 · 먼 산 바라기 등), 개발(역전승 · 첫 머지 · 백 걸음 등), 습관과 놀이(몰입의 시간 · 정시 퇴근 · 도감 완성 등), Claude Code 기능(기능 수집가 · Claude Code 탐험가)으로 나뉘고, 한 번 달성하면 계속 남으며 10~80코인을 받습니다. 역전승은 세 번 이상 실패한 테스트를 끝내 통과시켰을 때입니다. 토큰을 많이 쓴 걸로 주는 업적은 없습니다.

오늘의 퀘스트는 매일 쉬기 · 일 · 돌봄에서 하나씩 세 개가 나옵니다. 날짜와 펫으로 정해지므로 터미널을 여러 개 켜도 같은 퀘스트가 나오고, 진행도도 합쳐서 셉니다. 하나 끝낼 때마다 5코인, 셋 다 하면 10코인과 선물 상자를 받습니다. 못 끝낸 퀘스트는 다음 날 바뀔 뿐 잃는 건 없습니다. 띠 상태줄에 "퀘스트 1/3"으로 보이고, `/toko quests` · `/toko badges`나 방에서 자세히 봅니다.

### 집중 타이머

`/toko focus`로 25분 집중을 시작합니다(`/toko focus 50`처럼 5~120분). 집중하는 동안에는 권유 · 말풍선 · 랜덤 장면이 멈추고 띠에 남은 시간만 보입니다. 끝까지 하면 10코인을 받고, 다음 틈에 기지개를 권합니다. `/toko focus off`로 멈추면 보상은 없습니다. 방에도 시작과 그만하기 버튼이 있습니다.

### 컨텍스트 · 비용 미터

띠 아래 줄 오른쪽에 "컨텍스트 62% · $1.24 · 5시간 41%"를 보여 줍니다. Claude Code가 상태줄과 `/cost`에 쓰는 숫자 그대로이고, 사용 한도는 가장 많이 찬 창을 고릅니다. 컨텍스트 70% · 한도 75%부터 노란색, 컨텍스트 85% · 한도 90%부터 빨간색이 되고, 한도가 80%를 넘으면 리셋 시각을 붙입니다. 띠를 숨겨도 프롬프트 힌트 끝에 컨텍스트 %가 남습니다. 상태줄을 따로 쓰면 `/toko meter off`로 끕니다.

### 생각 주차장 메모

Claude가 일하는 동안 떠오른 딴생각을 `/memo 로그 포맷도 바꾸기`처럼 맡겨 둡니다. 턴이 도는 중에도 바로 받습니다. 턴이 끝난 틈에 토코가 "아까 맡긴 메모: …"를 꺼내고 입력창에 넣을지 묻습니다. 넣기는 쓰던 글 뒤에 붙이기만 하고 보내지는 않습니다. 나중에를 누르면 30분 뒤에 다시 꺼냅니다. 메모는 내 컴퓨터에만 두고 광장이나 모델로 보내지 않습니다.

### 오늘 한 일 요약

`/toko today`는 오늘 한 일과 진행 중인 일을 일 단위로 정리해 클립보드에 넣습니다. 세션마다 턴이 끝날 때 질문 앞 120자와 답 앞 240자를 내 컴퓨터에 남겨 두고(세션당 최근 24턴), 오늘 연 모든 세션(닫힌 세션 포함)의 기록을 작은 모델에 한 번 넘겨 묶습니다. 세션이 달라도 같은 일이면 한 줄로 합치고, PR 번호 · 버전 · 티켓은 답에 나온 그대로 붙입니다. 스탠드업이나 Jira 댓글에 그대로 붙여 넣으면 됩니다. 방의 [오늘 기록 복사] 버튼도 같습니다.

```text
10월 29일 (목) 한 일
- 배포 확인했어요 (0.2.17)
진행 중
- 리뷰 중이에요
```

작은 모델을 끄거나 하루 호출 한도를 다 썼거나, 작은 모델이 1분 안에 답하지 못하면 세션별 마지막 질문만 보여 주고 그 이유를 끝에 적습니다.

```text
10월 29일 (목) 한 일
- 「배포」 배포 봐 줘
- 「리뷰」 리뷰해 줘
(오늘 작은 모델 한도를 다 써서 세션별 마지막 질문만 보여요)
```

커밋 · 테스트 · 편집 줄 수 · 비용 같은 횟수는 `/toko <말>`로 토코와 이야기할 때 Claude에게 넘기는 메모에 들어갑니다.

### Claude Code 새 기능 소개

Claude Code가 업데이트되면 토코가 새로 생긴 기능 하나를 골라 쉬운 말로 알려 줍니다. 세션을 열고 8초쯤 뒤에 Claude Code 공식 CHANGELOG를 읽고, 지난번에 본 버전 다음부터 생긴 기능 가운데 터미널에서 코딩하는 사람 누구에게나 쓸모 있는 것 하나를 작은 모델이 고릅니다. 클라우드 세션 · 회사 설정 · 텔레메트리 · SDK · 모드 개발용 기능은 고르지 않습니다. 업데이트가 거의 매일 나오지만 대부분 버그 수정이라, 새 기능이 없는 업데이트에는 아무 말도 하지 않습니다. 처음 설치했을 때는 최근 다섯 번의 업데이트에서 하나를 고릅니다.

다음 틈에 토코가 "Claude Code 2.1.304에 새 기능이 생겼어: /auto-mode-setup. 들어 볼래?"처럼 묻습니다. `/toko answer 알려 줘`나 `/toko 알려 줘`로 답하면 무엇을 해 주는지, 언제 쓰면 좋은지를 대화창에 적고, 바로 해 볼 명령이 있으면 비어 있는 입력창에 넣어 둡니다. 나중에라고 답하면 30분 뒤에 다시 묻고, 안 볼래라고 답하면 그 소개를 넘깁니다. 한 버전은 한 번만 소개하고, 터미널을 여러 개 켜도 한 곳에서만 묻습니다. `/toko ai off`이면 소개를 건너뜁니다. 지난 소개는 `/toko news`나 방에서 다시 봅니다.

### 기능 도감

Claude Code 기능을 처음 써 볼 때마다 기능 도감에 도장이 찍히고 5코인을 받습니다. 쓸 줄 아는 기능이 늘어나는 걸 모으는 장치입니다. 모두 16가지이고, 8가지를 쓰면 기능 수집가, 16가지를 다 쓰면 Claude Code 탐험가 업적을 받습니다.

| 기능 | 이렇게 써요 |
|---|---|
| 대화 줄이기 · 새로 시작 · 이어 하기 · 되감기 | `/compact` · `/clear` · `/resume`(셸에서 `claude -c`도 됩니다) · `/rewind` |
| CLAUDE.md 만들기 · 메모리 보기 · 허용 규칙 | `/init` · `/memory` · `/permissions` |
| 모델 바꾸기 · 컨텍스트 보기 · 세션 이름 짓기 | `/model` · `/context` · `/rename` |
| 코드 리뷰 · 되풀이 맡기기 | `/code-review` · `/loop` |
| 계획 먼저 · 뒤에서 돌리기 | Shift+Tab으로 plan mode를 켜고 계획을 받기 · Ctrl+B로 명령을 뒤로 보내기 |
| 그림 붙여 넣기 · 파일 짚기 | Ctrl+V로 화면 캡처 붙여 넣기 · `@파일` |

명령은 내가 직접 입력했을 때만 셉니다. 계획 먼저는 Claude가 plan mode에서 계획을 내밀 때, 뒤에서 돌리기는 명령이 백그라운드로 돌 때 찍힙니다. 단축키 자체는 토코가 보지 못해서, 되감기를 Esc 두 번으로만 하면 도장이 찍히지 않습니다. `/toko features`나 방에서 아직 안 써 본 기능과 쓰는 법을 봅니다.

### 상황별 팁

아직 안 써 본 기능이 딱 맞는 순간이 오면, 토코가 틈에 그 기능을 한 번 권합니다. `/toko answer 써 보기`로 답하면 비어 있는 입력창에 명령을 넣어 두고, 알아라고 답하면 그 팁은 다시 하지 않습니다. 같은 팁은 하루에 한 번만 하고, 기능 도감에 오른 기능은 권하지 않습니다. 말풍선은 다른 권유와 같이 시간당 4번 안에서만 띄웁니다.

| 이럴 때 | 권하는 것 |
|---|---|
| 컨텍스트가 80%를 넘었을 때 | `/compact`로 대화를 요약해서 비우기 |
| 같은 명령의 권한 확인을 세 번째 받았을 때 | `/permissions`에 허용 규칙 넣기 |
| `/bonk`가 끝났을 때 | `/rewind`로 아까 시점으로 되돌리기 |
| CLAUDE.md가 없는 레포에서 세션을 열었을 때 | `/init`으로 CLAUDE.md 만들기 |
| "끝났어?", "다시 확인해 줘" 같은 부탁을 한 시간에 세 번 했을 때 | `/loop`로 되풀이 맡기기 |
| 커밋하고 아직 푸시하지 않았을 때 | `/code-review`로 리뷰받기. 그사이 푸시하면 권하지 않습니다 |

### 종족별 말투

펫은 종족마다 성격과 말투가 다릅니다. 알을 깰 때 작은 모델이 종족에 어울리는 성격과 말버릇을 짓고, 그 뒤로 모델이 쓰는 대사도 모두 종족 말투를 따릅니다. 모델을 끄거나 하루 호출 한도를 다 써도 말투는 그대로입니다. 준비된 대사에 종족 말투를 입혀 말합니다. 고양이는 말끝을 바꾸고, 곰 · 용 · 유령 · 로봇은 소리로 말을 꺼내고, 나머지 종족은 말끝에 소리를 붙입니다. 몇몇 대사는 종족에 맞게 따로 써 두었습니다.

| 종족 | 성격 | 말투 예 |
|---|---|---|
| 고양이 | 도도해 보여도 늘 곁에 붙어 있는 느긋한 고양이 | 같이 기지개 한 번 켤래냥? |
| 곰 | 서두르지 않고 기대어 쉴 품을 내어 주는 곰 | 음… 겨울잠까진 아니어도 오늘은 일찍 쉬자 |
| 병아리 | 작은 일에도 크게 기뻐하는 수다쟁이 병아리 | 통과다! 삐약삐약! |
| 토끼 | 작은 기척에도 귀를 쫑긋 세우는 수줍은 토끼 | 오래 앉아 있었네. 같이 깡충 뛰어 볼래? |
| 개구리 | 연잎 위에서 멍하니 쉬는 데 선수인 개구리 | 개굴, 물 한 모금 어때? 난 벌써 촉촉해 |
| 펭귄 | 줄을 맞춰 차례대로 하는 꼼꼼한 펭귄 | 20초만 먼 바다 보자. 내가 세어 줄게 펭! |
| 여우 | 네가 지친 걸 먼저 알아채는 눈치 빠른 여우 | 꾀가 안 날 땐 잠깐 쉬는 게 꾀야. 캥 |
| 용 | 겉은 위풍당당하지만 속은 여린 꼬마 용 | 크릉, 불은 내가 대신 뿜을게. 넌 숨만 고르자 |
| 유니콘 | 작은 일도 마법처럼 기뻐해 주는 유니콘 | 반짝반짝, 별가루 선물이야. o 눌러서 열어 봐 |
| 유령 | 겁주지 않고 살며시 곁에 머무는 수줍은 유령 | 스르르… 놀랐어? 오늘도 옆에 있을게 |
| 불사조 | 실패해도 괜찮다고 다독이는 따뜻한 불사조 | 한 번 더 하면 돼. 화르륵! |
| 로봇 | 다정함을 하나씩 배워 가는 성실한 로봇 | 삐빅. 수분 보충 시각이야. 물 한 잔 어때? |
| 우파루파 | 늘 웃는 얼굴로 천천히 사는 우파루파 | 뽀글, 물은 내 집이야. 너도 한 모금 마셔 |
| 데불이 | 밤새 기사를 읽어 아는 게 많은 데이블의 하늘색 부엉이 | 부엉, 밤은 내가 지킬게. 너는 이제 쉬어 |

### 토코와 이야기하기

`/toko 안녕!`, `/toko 오늘의 퀘스트는 뭐야?`처럼 정해진 명령이 아닌 말을 쓰면 토코에게 말을 겁니다. 답은 따로 모델을 부르지 않고 지금 세션의 Claude가 토코가 되어 하므로, 세션과 같은 토큰을 씁니다. Claude는 펫 카드 · 기분 · 욕구 · 코인 · 오늘의 퀘스트 · 오늘 한 일을 숨은 메모로 받아 그 안에서만 답하고, 답의 첫 줄은 띠의 말풍선에도 뜹니다. 메모 내용은 개수만 넘깁니다.

"간식 줘", "25분 집중할게"처럼 해 달라는 말이면 Claude가 `mcp__toko__command` 도구로 맞는 명령을 대신 실행합니다. `mute`, `quests` 같은 정해진 명령은 지금처럼 모델 없이 바로 실행됩니다.

### 명령

| 명령 | 동작 |
|---|---|
| `/toko <하고 싶은 말>` | 토코에게 말을 겁니다. 지금 세션의 Claude가 토코가 되어 답합니다 |
| `토코야 <말>` | 슬래시 없이 부르기. `/toko <말>`과 같습니다(펫 이름+아/야도) |
| `/toko` | 토코의 방(퀘스트 · 업적 · 도감 · 메모 · 상점 · 꾸미기 · 펫 뽑기 · 광장)을 엽니다 |
| `/toko close` | 열린 토코의 방을 닫습니다(방이 키를 쥐고 있으면 Esc, 아니면 ctrl+x x 도 같습니다) |
| `/toko help` | 명령 목록 |
| `/toko mute` · `unmute` | 말 걸기를 끄고 켭니다 |
| `/toko hide` · `show` | 띠를 숨깁니다. 쉬자고 할 때만 잠깐 나타납니다 |
| `/toko quiet 22-09` | 방해 금지 시간 |
| `/toko break 50` | 휴식 권유 간격(분) |
| `/toko off-work 19` | 퇴근 시각. 지나면 마무리 정리를 권합니다 |
| `/toko ai off` | 작은 모델을 부르지 않습니다. 규칙과 준비된 대사로만 움직입니다 |
| `/toko ai 60` | 작은 모델의 하루 호출 한도를 바꿉니다. 10~200, 기본 30 |
| `/toko notify on` | 집중 타이머가 끝나면 OS 알림을 하루 3번까지 보냅니다(기본 꺼짐) |
| `/toko shop` · `buy <id>` · `wear <id>` | 상점과 캐릭터 꾸미기. 애완동물도 여기서 데려오고 바꿉니다 |
| `/toko place <id> [자리]` · `store <id>` · `layout` | 방 꾸미기. 자리는 wall-left · wall-right · floor-1~4 · rug |
| `/toko visit <친구>` · `home` | 친구 방에 놀러 가기 · 데려오기 |

## 광장 서버

광장은 같은 서버에 접속한 사람들의 펫이 만나는 곳입니다. 플러그인의 `serverUrl` 기본값이 팀 광장(`https://toko-plaza.dllm.dable.io`)이라서 설치하면 바로 들어갑니다. 이 주소는 사내망에서만 열립니다. `/toko plaza link`가 주는 주소를 브라우저로 열면 광장 페이지가 내 펫을 알아보고 이름표에 "나"를 붙입니다. 방향키로 걷고, Enter를 눌러 말하면 펫 머리 위에 말풍선이 떠서 천천히 위로 날아갑니다. 다른 펫 가까이 가면 그 펫 이름표 아래에 손짓 메뉴가 뜨고, 숫자 1(손 흔들기) · 2(하트) · 3(간식) · 4(응원)를 누르거나 버튼을 눌러 보냅니다. 받은 쪽 Claude Code의 토코도 `/toko plaza wave`로 받은 것처럼 반응합니다. 움직인 자리와 말은 같은 채널을 보는 모두에게 바로 보입니다. 펫이 처음 광장에 오면 서버가 분수대를 피해 다른 펫과 떨어진 자리를 정해 주고, 움직이면 그 자리로 바뀝니다. 서버가 자리를 기억해서 새로고침하거나 나갔다 다시 들어와도 펫은 늘 같은 자리에 섭니다. 이 주소에는 내 광장 id가 들어 있어서 다른 사람에게 보내면 안 됩니다. 나가고 싶으면 `/toko plaza off`를 쓰고, 다른 광장을 쓰려면 `claude plugin configure toko --config serverUrl=<광장 주소>`로 바꿉니다. 비워 두면 토코는 혼자 지냅니다. 광장은 한 채널에 펫 20마리까지 받는 채널로 나뉩니다. 1번 채널은 늘 열려 있고, 처음 들어오면 서버가 자리가 남은 가장 앞 번호 채널에 넣어 주며, 모든 채널이 차면 다음 채널을 자동으로 엽니다. `/toko plaza channel`로 채널별 인원과 내 채널을 보고, `/toko plaza channel <번호>`로 다른 채널로 옮길 수 있습니다. 가득 찬 채널로는 옮길 수 없고, 가장 높은 채널 바로 다음 번호를 쓰면 새 채널이 열립니다. 친구 목록과 손 흔들기 · 하트 같은 손짓은 내 채널 안에서만 오가며, 다른 채널의 친구에게는 보낼 수 없습니다. 광장 페이지 오른쪽 위에서도 채널별 인원과 이 채널 멤버를 보고 채널을 옮길 수 있습니다. 내 펫과 아직 이어지지 않은 브라우저에는 "내 토코 연결하기" 창이 떠서, `/toko plaza link`가 준 주소를 붙여넣으면 바로 조종할 수 있습니다.

```bash
cd server
bun run plaza.ts                 # http://0.0.0.0:8080
docker build -t toko-plaza .     # 컨테이너로 띄울 때. uid 1000, HOME=/app으로 돕니다
```

`GET /`는 광장을 화면 전체에 픽셀 마을로 그리는 현황 페이지입니다. 오른쪽 위 방 구경 목록에서 열린 방을 고르면, 그 방의 장식 위에 주인과 손님 펫이 함께 보입니다. 목록의 이름은 광장에 보이는 펫 이름과 같습니다. 탭을 여러 개 켠 사람은 광장 펫과 같은 탭 기준으로 맞춥니다. 주인이 광장에 없는 방도 열린 채로 남는데, 이런 방은 "광장에 없음"을 붙여 목록 아래쪽에 둡니다. 데스크톱과 VS Code처럼 방 그림이 안 보이는 화면을 쓰는 사람도 여기서 방을 봅니다. 들어온 펫이 각자의 모습 그대로 분수대 광장을 돌아다니고, 이름표에 펫의 기분(신남 · 평온 · 졸림 · 걱정 · 삐짐)이 붙고, 신나면 음표를, 졸리면 z 를, 걱정되면 땀방울을 띄웁니다. 일하는 중인지 자리를 비웠는지는 페이지에도 공개 현황에도 보이지 않습니다. 새로 들어온 펫은 길을 따라 걸어 들어와 "놀러 왔어!"라고 말하고, 손짓을 보내면 그 대사가 말풍선으로 뜹니다. 저녁에는 노을이 지고 밤에는 가로등과 창문 불빛이 켜집니다. 그림을 보내지 않는 옛 플러그인의 펫은 같은 색의 기본 모양으로 그립니다. 오늘 누군가 `/bonk`를 했으면 왼쪽 아래에 뿅망치 전광판이 걸립니다. 전광판에는 오늘 Clawd가 맞은 횟수와 많이 나온 이유 3위까지가 뜨고, 전광판 오른쪽 위 작은 화면에서는 Clawd가 뿅망치를 맞고 납작해지는 장면이 되풀이됩니다. 브라우저에서 움직임 줄이기를 켜 두면 맞는 순간의 정지 그림만 보입니다. 아무도 때리지 않은 날에는 전광판이 없습니다. 페이지는 `GET /v1/ws`(WebSocket) 하나로 채널의 공개 현황(광장 id를 뺀 JSON)을 받는데, 서버가 바뀐 내용을 1초씩 모아서 한 번에 보내고, 걷기와 말은 같은 채널에 바로 보냅니다. 플랫폼 Ingress가 60초 동안 아무것도 오가지 않으면 연결을 끊어서 페이지가 25초마다 ping을 보내고, 끊기면 다시 붙습니다. 내 펫의 자리 · 말 · 손짓 · 채널 이동도 이 소켓으로 보내며, 소켓이 닫혀 있으면 `POST /v1/walk` · `POST /v1/say`로 보냅니다. 모두 지금 광장에 있는 펫의 광장 id로만 받고, 말은 1분에 12번까지이며 30초 동안 공개 현황에 남습니다. 0.1초 안에 몰린 걷기는 마지막 자리 하나만 0.1초 뒤에 반영합니다. 예전 페이지를 위한 `GET /v1/plaza/stream`(SSE)도 남아 있습니다. 같은 내용을 한 번 읽는 `GET /v1/plaza`도 있고, `GET /health`는 상태 확인용입니다.

플러그인 쪽은 `/plugin` → 토코 → 설정에서 `serverUrl`을 `http://<서버 주소>:8080`로 바꿉니다.

`TOKO_TUNER_KEY`에 Claude Tuner 조직 사용량 API 키(`ctk_…`)를 넣으면 광장에 데이블 Claude 날씨가 뜹니다. 서버가 3분마다 `GET /api/v1/usage/current`를 한 번 읽어 회사 전체 합계만 남깁니다. 남기는 값은 최근 사용량이 들어온 사람 수, 5시간 한도 평균 사용률, 60%를 넘은 사람 수, 다 쓴 사람 수입니다. 이메일과 사람별 숫자는 메모리에도 남기지 않고 바로 버립니다. 들어온 사람이 5명보다 적으면 날씨를 띄우지 않습니다. 평균이 10% 이상이거나 60% 넘은 사람이 2명 이상이면 북적북적, 평균이 20% 이상이거나 60% 넘은 사람이 5명 이상이면 축제입니다. 축제가 되면 현황 페이지에 깃발 줄이 걸리고 불꽃이 터지며, 토코는 그 순간 말풍선으로 한 번 알려 줍니다. `/toko plaza`에도 날씨 한 줄이 붙습니다. 읽기에 실패하면 15분까지는 마지막 날씨를 두고, 그 뒤로는 날씨를 내립니다. 현황 페이지 주소 끝에 `?weather=festival`을 붙이면 연출을 미리 볼 수 있습니다.

조직 키 하나로 데이블 사람 전원의 사용량을 읽을 수 있습니다. 그래서 키는 광장 서버 배포의 환경 변수에만 두고, 레포 · 배포 저장소 · 플러그인 · 채팅에는 넣지 않습니다. 서버는 키를 로그나 응답에 내보내지 않고, 서버 테스트가 페이지 · 응답 · 로그에 키가 섞이지 않는지와 레포에 실제 키가 들어 있지 않은지를 확인합니다.

펫끼리 건네는 짧은 인사말은 작은 모델이 씁니다. 서버는 아래 순서로 대사를 만들 길을 고릅니다.

1. `TOKO_DLLM_URL`이 있으면 그 OpenAI 호환 게이트웨이(`chat/completions`)를 부릅니다.
2. 없고 `CLAUDE_CODE_OAUTH_TOKEN`이 있으면 컨테이너 안의 Claude Code CLI(`claude -p --model haiku`)를 부릅니다. 배포 환경이 Claude Code OAuth 토큰을 넣어 주는 경우이고, 한 번에 두 개까지만 돌립니다.
3. 둘 다 없거나 답이 늦으면 준비된 대사로 대신합니다.

손짓을 보내면 서버는 바로 접수(202)하고, 대사는 뒤에서 만들어지는 대로 광장에 올립니다. 토코는 `curl -N`으로 `GET /v1/stream`(SSE)을 열어 두고 친구 목록 · 손짓 · 뿅망치 전광판을 받습니다. 서버는 바뀐 내용을 1초씩 모아 보내고, 친구 목록은 일하는 사람부터, 같은 상태끼리는 최근에 상태나 생김새가 바뀐 사람부터 30명까지 줍니다. `/bonk`를 하면 토코가 `POST /v1/bonk`로 이유의 유형만 보냅니다. 연결이 열려 있는 동안은 광장에 있는 것으로 치고, 상태나 생김새가 바뀔 때만 `POST /v1/poll`로 알립니다. 연결이 끊기면 1초부터 최대 60초까지 간격을 늘려 다시 붙고, 그동안과 `curl`을 띄울 수 없는 환경에서는 20초마다 광장을 확인합니다.

| 변수 | 뜻 |
|---|---|
| `PORT` | 서버 포트. 기본 8080 |
| `TOKO_DLLM_URL` | LLM 게이트웨이의 OpenAI 호환 주소. 예: `https://<게이트웨이>/v1` |
| `TOKO_DLLM_MODEL` | 게이트웨이의 모델 이름. 작은 모델(Haiku 급)을 권합니다 |
| `TOKO_DLLM_KEY` | 게이트웨이 키. 서버 환경 변수로만 두고 레포에 넣지 않습니다 |
| `TOKO_DLLM_TIMEOUT_MS` | 게이트웨이 응답을 기다리는 시간. 기본 2500 |
| `CLAUDE_CODE_OAUTH_TOKEN` | Claude Code CLI로 대사를 만들 때 쓰는 토큰. 배포 환경의 시크릿으로 넣습니다 |
| `TOKO_CLAUDE_MODEL` | Claude Code CLI의 모델. 기본 haiku |
| `TOKO_CLAUDE_TIMEOUT_MS` | Claude Code CLI를 기다리는 시간. 기본 20000 |
| `TOKO_TUNER_KEY` | Claude Tuner 조직 사용량 API 키. 데이블 Claude 날씨에 씁니다. 배포 환경 변수로만 넣습니다 |
| `TOKO_DATA_FILE` | 방 배치와 방문 기록을 남기는 파일. 기본 `server/data/plaza.json`. 컨테이너에서는 이 경로를 볼륨에 두어야 서버를 다시 띄워도 손님이 남습니다 |

광장에 보내는 정보는 펫 이름 · 종족 · 기분 · 상태(일하는 중 · 쉬는 중 · 자리 비움) · 생김새(현황 페이지에 그릴 작은 픽셀 그림) · 탭 표시(터미널을 켤 때마다 새로 뽑는 임의 값) · 입은 것(모자 · 목에 거는 것 · 안경의 아이템 id) · 방을 열어 두었을 때의 방 배치(자리마다 놓은 장식 id)와 방 그림 · 직접 켰을 때의 지금 하는 일(정해진 낱말이나 직접 정한 문구, 광장 친구 목록에만 보이고 현황 페이지에는 보이지 않음) · `/bonk`를 했을 때 이유의 유형(이유 문장은 보내지 않음)뿐입니다. 손짓 · 하트를 받은 쪽에 찾아가는 펫은 보낸 사람이 입은 것을 그대로 입고 갑니다. 생김새는 다른 펫에게 돌려주지 않고 현황 페이지에만 씁니다. 한 사람이 터미널을 여럿 띄우면 서버는 가장 바쁜 터미널의 기분과 생김새를 보여 주고, 45초 동안 소식이 없는 터미널은 셈에서 뺍니다. 코드, 프롬프트, 파일 이름은 보내지 않습니다. 서버는 접속 상태 · 손짓 · 뿅망치 전광판의 유형별 횟수를 메모리에만 두고(전광판에는 누가 때렸는지 남기지 않습니다), 90초 동안 소식이 없는 펫은 광장에서 지웁니다. 방 배치 · 방 그림(장식만 그린 작은 그림) · 방문 기록 · 방명록 스티커 · 받지 않은 선물만은 `TOKO_DATA_FILE`에 남겨서, 펫이 광장을 떠나도 손님은 방에 남습니다. 방 문을 닫으면 방 배치와 방 그림을 보내지 않습니다. 손짓과 뿅망치 보고는 각각 한 사람이 1분에 12번까지만 보낼 수 있습니다.
